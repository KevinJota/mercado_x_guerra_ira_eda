# EDA — Mercado Brasileiro e Conflito Irã-EUA

**Projeto em desenvolvimento**

Olá, Esse projeto consiste em uma **Análise Exploratória de Dados (EDA)** que busca relacionar acontecimentos e ações de Donald Trump durante o conflito entre Irã e Estados Unidos com movimentos do mercado financeiro brasileiro.

A análise será desenvolvida utilizando dados de mercado obtidos por meio do Profit e informações referentes aos acontecimentos e publicações analisados.

## Ativos

Inicialmente, o projeto será concentrado em:

* WINFUT
* PETR4.

## Tecnologias

* Python
* Pandas
* NumPy
* Matplotlib
* Jupyter Notebook

## Dados

Os arquivos brutos exportados do Profit não serão disponibilizados neste repositório.

Os gráficos e resultados apresentados serão derivados dos dados utilizados durante a análise.
